## Интерактивный CLI (демонстрация)

Скрипт demo.py — простое консольное меню поверх Warehouse. Нужен для показа системы «в действии»; в зачётные 15 итераций TDD не входит.

Запуск (из корня репозитория, в активированном окружении):

    python demo.py

Меню:

| Пункт | Действие | Что вводить |
|---|---|---|
| 1 | Показать все товары | — (просто Enter) |
| 2 | Добавить товар вручную | название, количество, дата поступления YYYY-MM-DD (можно пусто), дата отгрузки YYYY-MM-DD (можно пусто) |
| 3 | Добавить товар из заготовки | шаблон (например, яблоки), количество |
| 4 | Удалить товар | название |
| 5 | Изменить количество | название, новое количество |
| 6 | Изменить дату поступления | название, новая дата YYYY-MM-DD |
| 7 | Изменить дату отгрузки | название, новая дата YYYY-MM-DD |
| 8 | Поиск | название или префикс (регистр не важен) |
| 9 | Товары ниже порога | целое число-порог |
| 10 | Итого по складу | — |
| 11 | Сохранить склад в файл | путь (по умолчанию warehouse.txt) |
| 12 | Загрузить склад из файла | путь (по умолчанию warehouse.txt) |
| 13 | Экспорт отчёта в CSV | путь (по умолчанию report.csv), порог для is_low |
| 0 | Выход | — |

Формат файла склада: название;количество;дата_поступления;дата_отгрузки — одна строка на товар.

Локальные файлы warehouse.txt и report.csv добавлены в .gitignore — они не попадут в коммит.
